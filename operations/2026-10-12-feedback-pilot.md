# SZGuide：用户反馈与 AI 辅助运营试验

记录日期：2026-10-12。状态：用户确认后，版本 `45992e5` 已推送并上线；不是已获得的增长结果。

## 本轮选择

优先把已有指南的访客转为具体问题，再决定是否做 AI 旅行工具。已有内容获搜索点击，但点击不等于独立用户，反馈尚少。不添加数据库、账号、付费 API 或自动发信。

试验入口：15 篇指南末尾替换原来去联系页的提示，标题下提供直达入口。读者选择「有帮助／部分有帮助／仍有疑问」，再主动点击 Send feedback；主题、说明、回复邮箱全部可选。评级点击本身不发送数据。沿用既有 Formspree 表单，保留原联系页。

提交字段：reason、guide（规范 URL）、guide_title、helpfulness、experiment=guide-feedback-v1、可选 topic/message/email、当前页面可选的四个 UTM 标签。空邮箱不发送；不采集任意 URL 参数、浏览历史、护照、支付资料。来源标签仅代表进入该页面的标签，不能证明来源身份，也不跨页面保留。

## AI 辅助处理流程

1. 每次只处理一条去除个人信息的反馈，提供收到时间、对应指南及该指南最近复核日期。
2. 同时查看 Formspree Inbox 与 Spam，再使用 [分类提示词](./feedback-triage-prompt.md) 输出主题、原文依据、未知信息、建议动作。不能只依赖邮件通知；Spam 中的真实问题先人工核对。
3. 作者确认分类；涉及口岸、入境、费用与营业时间时核对一手来源后才能改正文。
4. 留下旧内容／改动／验证依据和版本；获同意跟进的读者可复测同一任务。发送必须另有明确授权。
5. 用 [评估样例](./feedback-evaluation.json) 检查误分类、编造来源、把账户邮件算用户需求、把合成样例当用户等错误。20 条均为合成边界样例，尚未运行评分，不能声称模型通过率。

## 观察与判定

建议发布后观察完整 7 天。10/18 可初次回看但不足完整七天；需要完整自然日比较时，用10/13–19并在10/20回看。10/12发布日与验收单列；没有创建自动监控。

记录：对应区间、指南浏览次数、成功提交数、yes/partly/no 数、具体未解决问题数、朋友／自然访客／自测来源、实施改动与复测结果。统计原始反馈需保存在本人私有位置；公开文档仅留去标识摘要，不放邮箱。

- 成功提交数以 Formspree 实际接收为准，不用按钮点击或浏览器动画计数。成功提交数／指南浏览次数仅是观察比值，不是独立用户转化率或组件曝光后的反馈率。
- 排除标记 SELF_TEST 的提交。匿名反馈不能可靠去重，不能把提交次数报成唯一用户数。
- 3–5 次试用足以发现具体卡点，不足以证明统计显著性。无人反馈时先检查入口、任务与渠道，不直接新增聊天机器人。
- 遇到明确且重要的问题可以立即修复，不必等七天。若同一问题多次出现，再优先考虑相关 AI 试验；安全关键问题即使仅一例也须核对。
- 本轮不保证流量、佣金或求职结果。代码与文案完成属于产出；真实任务完成与复测才属于用户结果。
